# My Portfolio Website

This is my personal portfolio website built with Astro. It is a simple place to show my projects, share blog posts, and let people contact me.

## Features
- Home page
- About page
- Projects section
- Blog/posts section
- Contact page
- GitHub Pages deployment ready

## Run locally
```bash
npm install
npm dev
```

## Build for production
```bash
npm build
```

## Deploy to GitHub Pages
1. Push your changes to GitHub.
2. Open your repository settings.
3. Go to Pages and choose GitHub Actions as the source.
4. The workflow in .github/workflows/deploy.yml will publish your site automatically.
